알바는 왜
레퍼첵이 없나요?

정규직엔 레퍼런스 체크가 있습니다. 하지만 알바는?
사업주는 지원자를 믿을 수 없어 쓰기 두렵고,
워커는 열심히 일해도 아무것도 남지 않습니다.

OJOb은 일한 만큼, 경력이 되도록 만듭니다
핵심 기능 — Features

기존과 다른
4가지 차이

단순한 구인구직이 아닙니다. 빠르고, 안전하고, 즉각 정산되는 새로운 방식입니다.

⚡

평균 12분 매칭

GPS 기반으로 반경 3km 내 가용 워커에게 즉시 푸시 알림. 빠르면 5분 내 매칭 완료.

🪙

당일 급여 정산

근무 종료 후 1시간 이내 앱 지갑으로 자동 입금. 주/월 단위 기다림 없이 바로 수령.

🎖️

스킬 인증 프로필

홀서빙·주방·배달 등 직종별 인증 뱃지로 믿을 수 있는 워커를 한눈에 확인.

🛡️

보험 자동 가입

근무 시작과 동시에 단기 근무자 보험 자동 연계. 사업주·워커 모두 안전하게.

NEW · 자동 포트폴리오

시프트 완료할 때마다
자동으로 쌓이는 커리어

근무할수록 리뷰와 통계가 자동 누적돼 공유 가능한 포트폴리오가 됩니다.

⭐

5개 항목 양방향 리뷰

태도·시간약속·업무능력·소통·팀워크. 사업주와 워커가 서로 평가합니다.

🔗

공유 가능한 웹 포트폴리오

ojob.kr/p/나의핸들 — 누구나 열람 가능, 직접 매칭 요청 가능.

📊

누적 통계 자동 계산

근무 시간, 수입, 재고용률이 실시간으로 업데이트됩니다.

공고 등록부터
정산까지 당일 완결

복잡한 절차 없이, 딱 4단계로 끝납니다.

01
📝

공고 등록 (3분)

사업주가 직종·시간·시급 입력. 즉시 게시.

02
🔔

근처 워커에 알림

반경 3km 내 워커에게 자동 푸시. 프로필 확인 후 선택.

03
✅

원탭 수락 → 출근

워커 수락 → QR 체크인 → 내비게이션 자동 연동.

04
💰

당일 자동 정산

근무 종료 후 워커 앱 지갑으로 즉시 입금.
